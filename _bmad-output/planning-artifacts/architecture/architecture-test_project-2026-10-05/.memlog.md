- (constraint) PRD final (2026-09-28): Python 3.9+, pip-installable, runs on Linux/macOS/Windows, no cloud SDK required for on-prem, 1 engineer 1 week, standalone CLI
- (constraint) PRD §5 Non-Goals: no UI, no real-time/streaming, no alerting, no auto-remediation, no orchestrator integrations, no schema drift, no multi-tenancy
- (decision) AD-1 Paradigm: Hexagonal/Ports-and-Adapters. Core domain (checks, models) is pure; connectors and writers are adapters behind ports. Prevents check logic from coupling to any data store or output format.
- (decision) AD-2 Connector port: BaseConnector ABC with read()→DataFrame as the single contract. Check functions receive DataFrames only, never connector objects. Prevents checks from coupling to source system type.
- (decision) AD-3 Check types as stateless pure functions: (config, source_df, target_df|None)→(CheckResult, sample_df|None). No state, no I/O. Prevents check functions from holding connections or calling writers directly.
- (decision) AD-4 ResultsWriter protocol: single write(result, sample_df) contract. Execution engine holds a ResultsWriter, never a concrete type. Prevents engine from knowing output format.
- (decision) AD-5 Pydantic v2 as single config parse boundary: raw YAML/JSON parsed once at CLI entry; all downstream code receives typed model instances, never dicts. Prevents scattered ad-hoc config access.
- (decision) AD-6 Env var resolution at parse time in parse_config(): no connector calls os.environ directly. Prevents env var handling scattered across connector implementations.
- (decision) AD-7 Sequential execution, no shared connector state across checks: each check instantiates its own connector, connects, executes, closes. Prevents a failed check's connection state bleeding into subsequent checks.
- (decision) AD-8 Cloud SDK extras as guarded optional imports: s3fs/adlfs/gcsfs imported inside try/except ImportError; missing extra raises ConnectorError with install hint. Prevents ImportError crashing on-prem deployments at module load.
- (decision) AD-9 Results Store validated before first check executes: writer.validate() called at CLI startup; unwritable path or unreachable DB aborts with non-zero exit before any checks run. Prevents silent result loss after a full check run.
- (decision) AD-10 Exit code contract owned by CLI: exit 0 iff all non-SKIP checks PASS; exit 1 on any FAIL or ERROR; all-SKIP exits 0. Prevents ambiguous CI/CD gate signals.
- (decision) AD-11 Dependency direction: checks/ and connectors/ and results/ must not import from each other; all three may import from config/ for shared model types only; cli.py is the only wiring point. Prevents circular deps and cross-layer coupling.
- (version) Stack: Python 3.9+ (min), Click 8.1, Pydantic 2.7, pandas 2.2, SQLAlchemy 2.0, PyYAML 6.0, snowflake-connector-python 3.x, databricks-sql-connector 3.x, pytest 8.x, ruff 0.4 [ASSUMPTION: versions current at authoring — not web-verified]
- (assumption) [ASSUMPTION] Databricks connector uses databricks-sql-connector (Python-native, no JVM) per OpenSpec design D6; JDBC approach explicitly rejected.
- (assumption) [ASSUMPTION] SQL connector uses SQLAlchemy + DBAPI drivers (pyodbc for ODBC, native drivers for PostgreSQL/SQL Server/Oracle); JDBC/JVM not used.
- (assumption) [ASSUMPTION] 10M row performance NFR met via query-pushdown for aggregate checks against SQL/Snowflake/Databricks; file-based checks limited by available memory — not validated by web research.
- (event) Reviewer gate complete. Version reviewer: 9 findings (Python EOL, stale version pins). Adversarial reviewer: 6 findings (CheckResult home, validate() contract, Protocol location, ConnectorError import, AD-6 ambiguity, class-level state). Applying all clear fixes before finalizing.
- (decision) AD-11 sub-rule: shared data shapes (CheckResult, CheckConfig subtypes) live in config/models.py; all Protocol/ABC definitions live in config/protocols.py (ResultsWriter, BaseConnector); cross-cutting exceptions (ConnectorError, ConfigurationError) live in config/exceptions.py. No other module defines a Protocol or base exception.
- (decision) AD-4 tightening: validate() returns None and raises ConfigurationError (from config/exceptions.py) on failure; never returns a boolean.
- (decision) AD-6 tightening: parse_config() records missing-var field names in ParseResult.missing_env_vars: list[str]; engine short-circuits to ERROR for any check whose connector config references a missing variable, without instantiating the connector.
- (decision) AD-7 tightening: connector implementations must hold no class-level or module-level mutable state; all connection state must be instance-level and fully released in close().
